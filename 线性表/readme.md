## 线性表

### 顺序表

通过静态数组来存储，实现以下函数：

1. `void InitList();`
2. `bool ListInsert(int i, T e);`
3. `bool ListDelete(int i,T& e);`
4. `int LocateElem(T e);`

### 单链表

1. `bool InitList();`
2. `int Length();`
3. `LinkList<T>* GetElem(int i);`
4. `LinkList<T>* LocateElem(T e);`
5. `bool ListInsert(int i, T e);`
6. `bool ListDelete(int i, T& e);`

### 双链表

1. `bool InitList();`
2. `int Length();`
3. `LinkList<T>* GetElem(int i);`
4. `LinkList<T>* LocateElem(T e);`
5. `bool ListInsert(int i, T e);`
6. `bool ListDelete(int i, T& e);`
